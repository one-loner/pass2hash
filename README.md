# Pass2hash

Генератор хеша пароля. Простая PHP-страница в тёмном минималистичном стиле. Пользователь вводит пароль и подтверждение. Если значения совпадают, страница выводит хеш, созданный функцией `password_hash()` с алгоритмом `PASSWORD_DEFAULT`. Если пароли различаются, отображается ошибка.   
Результат является эквивалентом выполнения команды: php -r "echo password_hash('PASSWORD', PASSWORD_DEFAULT), PHP_EOL;"

## Требования

- PHP 7.0 или новее
- Веб-сервер с поддержкой PHP
